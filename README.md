# news-image-20261126

One image summing up the world's news of Thursday 26 November 2026, drawn as a newspaper front page: Kim Jong Un calls for wider tactical nuclear weapons deployment; Saudi forces intercept a Houthi cruise missile; India marks 18 years since the 26/11 Mumbai attacks and Constitution Day; Thanksgiving Day in the United States; Game 3 of the World Chess Championship in Geneva; and BepiColombo's closer pass of Mercury.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This validates `entry.png` (PNG magic, at most 1 MiB, at most 1024x1024, complete IEND chunk) and copies it to `out/entry.png` with mode 0644. Every run writes the same bytes.
